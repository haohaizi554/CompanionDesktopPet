# v1.4.0

本版本把 v1.3.0 的 30,000 条逐条 authored 语料与 v1.2.1 已审计的 52,132 条 legacy 运行时合并，形成 82,132 条统一运行库，共 1,723 个语义场景。运行时不是按库存数量随机抽取：所有安全门禁通过后，调度器以最近 100 次播放为窗口，将 legacy 实际播放稳定在约 30%。

## 发布亮点

- authored 分区精确为 30,000 条；legacy 分区精确为 52,132 条，其中旧 curated 内容 806 条、hash-bound legacy surface 51,326 条。
- 两套分区独立重建后按稳定 ID 合并。运行库 SHA-256 为 `339358c524785db30badf420a3bdc2b89c7753486e907ff1a5216f68ca5d7ece`，没有修改 v1.2.1 或 v1.3.0 的历史标签与证据。
- `source_tier` 由现有 `source_kind` 派生，不增加 TSV 字段。最近历史少于 20 条时仅用评分靠近目标；达到 20 条后，总体接受区间为 25%–35%，每个模拟 seed 的接受区间为 20%–40%。
- 来源配额在触发器、上下文、语义冷却、每日上限、打扰预算、隐私、身份彩蛋和关系画像等硬门禁之后执行；某一来源没有安全候选时允许另一来源兜底，不会为了凑比例播放不合格内容。
- v1.3.0 历史记录没有来源字段，加载时安全默认成 authored；v1.4.0 新记录会保存实际来源。未知来源枚举仍会拒绝加载。
- legacy 关系画像统一保持 `neutral`。legacy 的 `dry_sharp` 通过固定哈希规则只选入 4 个场景：`technical.dry_sharp.god_class`、`technical.dry_sharp.todo`、`technical.topic_database_17a29d45a7d8`、`technical.topic_debugging_762b380363f8`；加上 authored 的 8 个，运行库精确为 12 个 dry-sharp 场景。

## 验证结果

- 正式模拟覆盖 30 天 × 100 个固定 seeds，共 15,000 次计划播放，实际输出 15,000 次，返回空结果 0 次，hard violations 0 个。
- legacy 实际播放 4,511 次，占 30.07%；100 个 seed 分别落在 29.33%–30.67%，全部通过独立 seed 门禁。
- 技术类播放 17.75%、Easter egg 9.89%、`dry_sharp` 2.00%、seasoning 1.32%；冷却、相邻特殊组、上下文和回复要求均无硬违规。
- 模拟报告 SHA-256 为 `2fceb9aecd6817dedf4c3690938c0c1656c97eeff4af8558f300791091597952`；可供 validator 重放的事件文件 SHA-256 为 `84c05704368bc5a18946342e2f6d5cef113ebc345aa9ac7f3b8037f45b6a8fd2`。
- 联合 validator 为 0 hard errors。唯一 warning 是 51,326 条 legacy surface 的原始库存形态观察；它明确不参与播放验收，播放暴露由独立的 hash-bound 模拟门禁控制。
- 标签流水线会重新执行 Python、.NET Release、合约测试、single-file 边界检查、真实 WPF 隔离 smoke、ProductVersion 与 SHA-256 校验；实际测试总数和二进制证据以该标签的 CI 日志及 `SHA256SUMS.txt` 为准。

## 下载与运行

- 推荐下载 `Jiayi-Desktop-Pet-win-x64.zip`；ZIP 内包含 `佳怡桌宠.exe`、`使用说明.txt` 和四份法律文件。
- 也可以直接下载 `Jiayi-Desktop-Pet.exe`，并同时阅读 `Jiayi-Desktop-Pet-README-zh-CN.txt`。
- 应用为 Windows x64、self-contained 单 EXE；不需要安装 Python 或 .NET SDK，旁边不需要应用 DLL、JSON 或 PDB。

## 离线、单 EXE 与签名说明

- 应用完全离线运行，不读取输入内容、剪贴板或窗口标题，也不枚举用户目录。
- 应用不包含热更新、自动更新或联网下载代码的机制；升级需要手动下载并替换 EXE。
- 当前 EXE 未做 Authenticode 代码签名；标签门禁会确认状态为 `NotSigned`、无签名证书和时间戳证书。从网络下载时，Windows SmartScreen 或安全软件可能显示信誉提示。
