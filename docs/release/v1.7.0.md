- 回车发送；浮窗只在输入时占用键盘；气泡底部留出最后一行。

- 语音固定发到 `http://43.138.138.200:8765`，由这台电脑的显卡合成。

- 语音不再探测空闲端口。

- 平板对话不再依赖本机 `8766`。
